# ANC-AI-Project

## AI-Based Adaptive Noise Cancellation Using Machine Learning

This project uses machine learning techniques to reduce unwanted noise from an audio signal and produce a cleaner output signal.

## Features

- Audio noise reduction
- Machine learning based adaptive noise cancellation
- Input and output signal analysis
- Improved audio quality

## Technologies Used

- Python
- Machine Learning
- NumPy
- SciPy
- Librosa
- Matplotlib

## How to Run

Run the application using:

ANC_AI_App.bat
